# tab5_synth — M5Tab5 + Unit Synth シンセサイザー

M5Stack **Tab5** に **Unit Synth**（U178 / SAM2695）を接続して使う、ループ型のタッチシンセサイザーです。
ドラムとメロディをタッチ操作で重ね録りし、クォンタイズでタイミングを整え、SDカードへ標準MIDIファイルとして書き出せます。書き出したMIDIの読み込みもできます。

*A loop-based touch synthesizer for M5Stack Tab5 + Unit Synth (SAM2695): 4–16 bar loops, overdub recording, non-destructive quantize, piano-roll editing, and Standard MIDI File export/import via microSD.*

## 機能

### RHYTHM モード
- ドラムパッド10種（Kick / Snare / Closed HH / Open HH / Clap / Tom-H / Tom-L / Crash / Ride / Bell）
- ループ再生しながらの重ね録り（オーバーダビング）
- ステップグリッド編集：選択した楽器の16ステップ×表示小節を表示し、タップで音の配置・削除。小節は `< n / N >` で切り替え
- UNDO（最後の音を取り消し）/ ドラム全消し

### MELODY モード
- 61鍵タッチキーボード（MIDI 36–96、C2–C6）
  - 白鍵15個分の窓表示＋全体ストリップのドラッグでスライド移動、オクターブ移動ボタン
  - マルチタッチ対応（和音演奏）、指を滑らせるとグリッサンド
- 音色選択：GM 128音色の一覧から選択（音色は曲全体で1つ）
- GRID画面：ピアノロール式のステップ編集
  - 縦軸＝音高（12半音表示、オクターブ／半音単位の窓移動、開くと録音済み音域に自動フィット）
  - 音の開始セルと長さ分の続きセルを表示、タップで配置・削除、配置する音の長さ（16分／8分／4分／2分）を選択可能
  - 置いた音のセルを横にドラッグすると、その音の長さを16分ステップ単位で伸ばし縮みできる

### EDIT / PLAY モード
- テンポ（60–200 BPM）
- 全体音量／メロディ音量／ドラム音量（%指定、0でミュート）
- メロディの音の長さ（%指定、スタッカート〜レガート）
- 書き出し時のループ繰り返し回数（1–8）
- ループ小節数（4 / 8 / 12 / 16小節）
- **LOAD MIDI (SD)** ボタン：SDカード上のMIDIファイルを読み込んで曲データに戻す

### 共通
- **非破壊クォンタイズ**：録音データは生のタイミング（tick）のまま保持し、再生・書き出し時にだけグリッド（16分／8分）と強さ（100%／50%）を適用します。人の演奏のブレを後から何度でも調整できます
- **MIDI書き出し**：SDカードへ標準MIDIファイル（SMFフォーマット1、PPQ 480）を出力。PCのメディアプレイヤーやDAWでそのまま再生できます。上書きせず、`tab5song.mid`、`tab5song2.mid`、…と連番で保存します（最大99）
- **MIDI読み込み**：書き出したファイルを読み込んで再生・再編集できます（テンポと音色も復元）。読み込みは現在のループ小節数分を取り込み、LOADボタンを押すたびに番号順の次のファイルに進みます
- メトロノーム（録音時、1拍目アクセント）

## 配線

Tab5 の **HY2.0-4P ポート（PORT.A）** と Unit Synth を付属の Grove ケーブルでつなぐだけです。

Unit Synth は受信専用で、黄線が UART_RX です。Tab5 側は **TX = G53**（白線側 G54 は未使用）で通信します（スケッチ内で設定済み）。

## ビルド方法（Arduino IDE）

1. Arduino IDE に M5Stack ボードマネージャを追加し、ボードパッケージをインストール
2. ボードに **M5Tab5** を選択
3. ライブラリマネージャで以下をインストール
   - **M5Unified**（0.2.23 以上）
   - **M5GFX**（0.2.30 以上）
   - **M5Unit-Synth**（最新版）
4. `tab5_synth.ino` を開いてコンパイル・書き込み
   - 書き込みできないときは、本体の電源ボタンを緑LEDが速く点滅するまで長押しするとダウンロードモードに入ります

## 使い方

- 上部のタブでモードを切り替えます。トランスポート（REC / PLAY / STOP / Q / EXPORT）は全モード共通です
- **REC**：ループが回り始め、その位置に演奏が重ね録りされます。もう一度押すと録音だけ止まります
- **PLAY**：ループ再生、**STOP**：停止
- **Q**：クォンタイズ設定の切り替え（OFF → 16分100% → 16分50% → 8分100%）
- **EXPORT**：SDカードにMIDIを書き出します（ループ×設定回数分）。ファイルは連番で保存され、上書きされません
- **LOAD MIDI (SD)**（EDIT画面）：SDカードの `tab5song*.mid` を番号順に読み込みます。押すたびに次のファイルに進むので、読み込んだファイル名は画面下の表示で確認してください

曲のデータモデルは「ループ」です（小節数は EDIT の LOOP BARS で 4/8/12/16 から選択）。まず RHYTHM で土台を作り、MELODY で鍵盤演奏を重ね、GRID で1音ずつ直し、EDIT で仕上げて書き出す、という流れを想定しています。

長い曲を LOAD するときは、先に LOOP BARS を曲の小節数に合わせておいてください（LOAD は現在のループ小節数分だけを取り込みます）。

## 設計メモ

- 時間単位は PPQ 480 の tick。録音は生 tick で保存し、クォンタイズ・音量・音長は再生／書き出し時の変換として適用（元データは不変）
- ループ小節数を減らしても、はみ出た音のデータは残ります（鳴らなくなるだけ）。戻せばまた鳴ります
- 書き出し済みファイルはクォンタイズ／音長% 適用後の状態なので、LOAD で取り込むとその状態の音符として取り込まれます
- SDカードへのアクセスは SPI モード（CS42 / SCK43 / MOSI44 / MISO39）を第一候補とし、失敗時は SDIO（SD_MMC）に自動フォールバックします
- マルチタッチの離鍵検出は、毎フレーム「現在触れているタッチID」との照合方式で、離したイベントを取りこぼしても音が残らないようにしています
